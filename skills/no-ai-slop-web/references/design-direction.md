# Menentukan Arah Desain per Produk

Isi tabel ini SEBELUM menulis kode. Jika proyek sudah punya design system, perluas — jangan ganti.

| Keputusan | Pertanyaan pemandu |
|---|---|
| Produk & audiens | Siapa pemakainya? Konteks pakai (HP di jalan, laptop kantor)? |
| Aksi utama | Satu hal yang harus dilakukan pengunjung? |
| Metafora visual | Satu gagasan visual yang berasal dari produk nyata |
| Tipografi | Satu/dua keluarga font, skala ukuran, panjang baris nyaman |
| Warna | Peran: latar, permukaan, teks, aksen, status. Cek kontras |
| Spasi & ritme | Satuan dasar, kepadatan, jeda antar section |
| Permukaan | Border/bayangan/radius — satu bahasa konsisten |
| Ikon | Satu set, satu gaya, ada nama aksesibel |
| Feedback | hover, focus-visible, active, loading |
| Motion | Perlu? Jika ya: tujuan, durasi, keadaan akhir, reduced-motion |

## Uji akhir
"Jika ganti logo dan nama, apakah ini masih terasa seperti produk ini?" Jika tidak, konsepnya masih generik.
